## Proyectos Destacados - Sistema RAG Bancario Multinube (BBVA)
- **Descripción**: Implementación de un pipeline RAG (Retrieval-Augmented Generation) de grado empresarial para flujos bancarios.
- **Arquitectura y Seguridad**: Despliegue con aislamiento de red estricto en entornos multinube (GCP/AWS). Integración de embeddings semánticos protegidos mediante encriptación en tránsito y reposo (KMS).
- **Stack Tecnológico**: GCP, AWS, KMS, VPC, Embeddings Semánticos.

## Proyectos Destacados - Ecosistema Local de IA Segura (Proyecto Práctico)
- **Descripción**: Desarrollo de un sistema RAG on-premise diseñado para demostrar la aplicación de arquitecturas Cloud y DevSecOps en un entorno local.
- **Implementación**: Construcción de una API mediante FastAPI, conectada a un LLM y a una base de datos vectorial local.
- **Prácticas DevSecOps**: Contenerización de la aplicación (Docker) con ejecución de escaneos de vulnerabilidades (SAST mediante checkov) sobre los Dockerfiles. Implementación de simulaciones de control de accesos y protección de variables de entorno para emular un entorno Zero Trust empresarial.
- **Stack Tecnológico**: Python, FastAPI, Docker, checkov, LLMs locales, Bases de Datos Vectoriales.
